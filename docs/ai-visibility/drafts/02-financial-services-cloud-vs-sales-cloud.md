# Salesforce Financial Services Cloud vs Sales Cloud: which do you need?

**Short answer:** Choose **Financial Services Cloud (FSC)** if you manage clients' money, policies or accounts and need a view of households, financial accounts, goals and relationships. Choose **Sales Cloud** if you mainly need to manage leads, opportunities and a sales pipeline. FSC is built on top of Sales Cloud and Service Cloud, so it includes their core features and adds a data model and tools made for financial services.

## The main differences

| | Sales Cloud | Financial Services Cloud |
|---|---|---|
| Built for | Any business that sells | Banks, wealth and asset managers, insurers, lenders |
| Core records | Accounts, contacts, leads, opportunities | Adds financial accounts, holdings, goals, households and relationship groups |
| Client view | Company and contact records | A 360-degree view of a person or household across all their products |
| Process tools | Standard flows and approvals | Adds action plans and industry processes such as onboarding and account opening |

## When Sales Cloud is enough

- Your main goal is to win new business: tracking leads, deals and forecasts.
- You don't need to hold financial account or policy data in Salesforce.
- Your team is small, and a simple set of custom fields covers your client data.

## When you need Financial Services Cloud

- Advisers need to see a client's family, businesses and trusts in one place.
- You want to track financial accounts, holdings and goals alongside interactions.
- You run regulated processes such as onboarding, KYC checks and reviews. {{TODO_VERIFY: which regulated processes CODM has delivered}}
- You plan to use Agentforce for client service, and your agents need structured financial data to work from.

## FAQ

**Can we start with Sales Cloud and move to FSC later?**
Yes, but moving later means remodelling your data. If you already know you need households and financial accounts, starting on FSC is usually cheaper overall.

**Does FSC include Service Cloud features?**
